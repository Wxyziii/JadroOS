# Instructions for coding agents
Read README, product requirements, relevant ADRs, threat model and roadmap before changes. Preserve confirmed decisions: actual macOS visual references only, individual-window Alt+Tab, General-default Spotlight, official Instant route, independent Claude/Codex, Arch foundation and explicit Windows reboot. Do not invent provider support, quota rules, build results or screenshots.

Work one scoped milestone ticket at a time. Inspect repository before editing, avoid unrelated rewrites, use small reviewable diffs, add acceptance tests, run relevant checks, report exact commands and failures. Mark placeholders and experimental code. Never store secrets, use undocumented provider endpoints, scrape cookies, automatically bill, grant arbitrary root, bypass anti-cheat, or run disk/firmware operations on host. No Apple proprietary assets or third-party KDE lookalike visual references. Use VM and mock adapters before real operations. Human approval for privilege, billing, destructive changes, releases and license choices. Do not merge or publish releases automatically.
