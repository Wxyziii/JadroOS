# System apps (planned, Phase 6+)

Normal Qt Quick applications (not part of the Quickshell shell) sharing the design-system components. UI: Claude; backends/adapters: Codex. See [system-apps.md](../docs/product/system-apps.md).

| App | Phase |
|---|---|
| Shared component library | 6 (T6.1) |
| Settings, Files, Welcome, Activity, Devices, App Center, Remote | 6 |
| Intelligence (AI providers, history, consent) | 7 |
| Gaming Center | 8 |
| Backup, phone sharing | 9 |

Create an app's folder when its ticket starts. Keep UI separate from privileged operations; use upstream backends.
