# Official macOS visual references
All images below are **actual Apple promotional screenshots/photos**, externally linked to their original publisher, not JadroOS implementations. They are reference material only; do not bundle them in the OS or mirror them in releases without rights. If a remote image fails, use its source page. Golden Gate is current; Tahoe gives detailed published reference views.
