# ADR-0002: Explicit provider routing
Status: confirmed UX, proposed adapters. General default; ChatGPT Instant official app/site only; Medium/High/Extra High selectable when supported, native SIWC requires eligibility; Claude chat and Claude Code separate; Codex separate. Alternatives: API-only (separate cost/history), scraping web (unsupported/brittle), automatic fallback (quota surprise). Consequences: manual prompt copy may be required; native history separate. Validate documented app handoff and actual provider account access. No silent paid or agent route; no automatic mode escalation.
