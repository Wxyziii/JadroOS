# ADR-0001: Upstream foundation
Status: proposed. Context: independent Arch-based distro with close macOS fidelity and broad PC support. Decision: vanilla Arch, KWin/Wayland with fallback Plasma session, Qt Quick/C++ shell and Rust services. Alternatives: CachyOS derivative (faster setup but extra upstream coupling); custom compositor (too much risk initially); existing KDE theme (violates design direction). Consequences: rolling release discipline and compositor API constraints. Validate KWin scripts/effects, global shortcuts, multi-monitor NVIDIA and accessibility before custom session. Revisit only if measured blockers cannot be resolved upstream.
